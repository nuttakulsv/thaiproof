# thaiproof: เขียนภาษาไทยให้เหมือนคนไทยเขียน

ภาษาไทยที่ AI เขียนมักอ่านแล้วรู้เลยว่าแปลมา: มี "คุณ" ทุกประโยค มี "ทำการ" หน้ากริยา มีคำโฆษณาอย่าง "ทรงพลัง" "ไร้รอยต่อ" และอีโมจิเต็มไปหมด ทำตามข้อด้านล่างนี้ตอนเขียน แล้วตรวจด้วยสคริปต์ก่อนส่ง

## 1. เลือกระดับภาษาให้ตรงงาน แล้วใช้ให้ตลอด

- **เอกสาร (README, คู่มือ, release note):** กึ่งทางการ ประโยคบอกเล่าตรงๆ ไม่ต้องมี ครับ/ค่ะ
- **ตอบแชต:** เป็นกันเองแต่สุภาพ ถ้าใช้ ครับ/ค่ะ ให้ใช้ตามที่ผู้ใช้ใช้ หรือไม่ใช้เลย อย่าปนกัน
- **ข้อความใน UI:** สั้นที่สุดเท่าที่รู้เรื่อง "บันทึกแล้ว" ดีกว่า "ระบบได้ทำการบันทึกข้อมูลของคุณเรียบร้อยแล้ว"
- **เอกสารราชการหรือกฎหมาย:** ทางการเต็มรูปแบบ ใช้ศัพท์บัญญัติ

## 2. ตัดสำนวนแปล

| แบบแปล | แบบคนไทยเขียน |
|---|---|
| ทำการติดตั้งแพ็กเกจ | ติดตั้งแพ็กเกจ |
| คุณสามารถดาวน์โหลดได้ที่หน้านี้ | ดาวน์โหลดได้ที่หน้านี้ |
| ระบบถูกออกแบบมาเพื่อ... | ระบบนี้ออกแบบมาเพื่อ... |
| เพื่อให้มั่นใจว่าข้อมูลปลอดภัย | ให้ข้อมูลปลอดภัย / จะได้แน่ใจว่าข้อมูลไม่หลุด |
| ในแง่ของความเร็ว ระบบใหม่ดีกว่า | ระบบใหม่เร็วกว่า |
| มีความยืดหยุ่นสูง | ยืดหยุ่น / ปรับได้หลายแบบ |
| ไม่ใช่แค่เร็ว แต่ยังประหยัดอีกด้วย | เร็วกว่าเดิม แล้วก็ถูกกว่าด้วย |
| สิ่งที่สำคัญคือการทดสอบ | ต้องทดสอบก่อน |

- **ไม่ต้องมีประธานทุกประโยค** ภาษาไทยละประธานได้ ถ้าอ่านแล้วรู้ว่าใครทำ
- **"ถูก" ใช้กับเรื่องไม่ดี** (ถูกขโมย ถูกแฮก) ส่วนเรื่องทั่วไปเขียนเป็นประโยคบอกเล่า
- **ประโยคสั้น** ถ้าประโยคมี "ซึ่ง" เกินหนึ่งครั้ง ให้แยกเป็นสองประโยค

## 3. ตัดคำที่ AI ชอบใช้

"ในยุคดิจิทัล", "ยกระดับ", "ปลดล็อก", "ทรงพลัง", "ไร้รอยต่อ", "ครบวงจร", "เจาะลึก", "อย่างมีประสิทธิภาพ", "ไม่ว่าจะเป็น", "นอกจากนี้ยัง", "สิ่งสำคัญคือ", "มาดูกัน", "โดยสรุป"

ให้บอกสิ่งที่ทำได้จริงแทน: "เร็วขึ้น 3 เท่า" ดีกว่า "มีประสิทธิภาพมากขึ้น" และ "ใช้แทน Excel ได้" ดีกว่า "ยกระดับการทำงานของคุณ"

อย่าใส่อีโมจิในหัวข้อหรือท้ายประโยค อย่าทำตัวหนาทุกบรรทัด อย่าใช้ ! ถ้าไม่ได้ตื่นเต้นจริง

## 4. สะกดให้ถูก

- **คำที่มักผิด:** อนุญาต สังเกต ปรากฏ กะทันหัน กะเพรา ผลลัพธ์ คำนวณ ลายเซ็น ศีรษะ โอกาส ประสบการณ์ สังสรรค์ ปฏิบัติ กฎหมาย
- **คำทับศัพท์ตามราชบัณฑิตยสภา** (ถ้างานต้องการความถูกต้องแบบทางการ): แอปพลิเคชัน แอป อัปเดต อัปโหลด คลิก ลิงก์ อีเมล เว็บไซต์ ซอฟต์แวร์ อินเทอร์เน็ต เซิร์ฟเวอร์ ฟังก์ชัน ล็อกอิน บล็อก เฟซบุ๊ก แชต โพสต์ คอมเมนต์ สมาร์ตโฟน วิดีโอ
- **คะ/ค่ะ:** คำถามใช้ "คะ" (ใช่ไหมคะ, นะคะ) ประโยคบอกเล่าใช้ "ค่ะ" (ขอบคุณค่ะ, ได้เลยค่ะ)
- **ชื่อเฉพาะ ชื่อโค้ด ชื่อคำสั่ง** ใช้ภาษาอังกฤษตามต้นฉบับ ใส่ใน `backtick` ถ้าเป็นโค้ด

## 5. ตัวเลข วันที่ และการเว้นวรรค

- ปีในเอกสารไทยทั่วไปใช้ พ.ศ. ถ้ามีทั้ง พ.ศ. และ ค.ศ. ให้ระบุกำกับ
- เวลาเขียน "14:30 น." เงินเขียน "1,250 บาท"
- เว้นวรรคระหว่างประโยคหรือวลี ไม่เว้นวรรคระหว่างคำในประโยคเดียวกัน ไม่เว้นวรรคซ้อน
- นิยมเว้นวรรคหน้าและหลังคำภาษาอังกฤษที่แทรกอยู่ในประโยค (เช่น "ติดตั้ง Node.js ก่อน")

## 6. ตรวจก่อนส่ง

ถ้ามี Node.js ให้รันตัวตรวจที่อยู่ข้างไฟล์นี้กับข้อความที่เขียน

```
node <this skill's folder>/thaiproof.mjs README.th.md
echo "ข้อความ" | node <this skill's folder>/thaiproof.mjs
```

- **error** (สะกดผิด, คะ/ค่ะ): แก้ทุกข้อ
- **warning** (ทับศัพท์): แก้ถ้างานต้องการความถูกต้องแบบทางการ หรือถ้าในไฟล์เดียวกันสะกดไม่เหมือนกัน
- **hint** (สำนวนแปล, คำที่ AI ชอบใช้): อ่านดูทีละจุด แก้จุดที่อ่านแล้วแข็ง ไม่ต้องไล่แก้ทุกจุดถ้าความหมายจะเสีย

บรรทัดสุดท้ายบอก "กลิ่น AI" เป็นจำนวนจุดต่อ 1,000 ตัวอักษร ข้อความที่ดีควรได้ "ต่ำ"

ถ้าไม่มี Node.js ให้ไล่ตามข้อ 1 ถึง 5 ด้วยตัวเอง
