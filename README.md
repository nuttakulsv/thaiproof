# thaiproof

[English](README.en.md) · **[ลองใช้บนเว็บ](https://nuttakulsv.github.io/thaiproof/)** · จากคนทำ [thai-id-card-kit](https://github.com/nuttakulsv/thai-id-card-kit) และ [engineering-ladder-th](https://github.com/nuttakulsv/engineering-ladder-th)

ภาษาไทยที่ AI เขียนอ่านแล้วรู้เลย

> 🚀 ยินดีต้อนรับสู่แอพพลิเคชั่นของเรา! ในยุคดิจิทัลปัจจุบัน ระบบนี้ถูกออกแบบมาเพื่อช่วยให้คุณสามารถทำการจัดการงานของคุณได้อย่างมีประสิทธิภาพและไร้รอยต่อ ...ติดต่อเราได้ตลอด 24 ชั่วโมงนะค่ะ 💬

คนไทยไม่ได้พูดแบบนี้ มี "คุณ" ทุกประโยค มี "ทำการ" หน้ากริยา มีคำโฆษณาที่ไม่มีใครใช้จริง และยังเขียน "นะค่ะ" อีก

thaiproof มีของสองอย่าง

1. **ตัวตรวจภาษาไทย** ใช้ได้ทั้งบนเว็บ ใน terminal และใน CI ตรวจคำสะกดผิด คำทับศัพท์ตามราชบัณฑิตยสภา คะ/ค่ะ สำนวนแปล และคำที่ฟ้องว่า AI เขียน แล้วให้คะแนน "กลิ่น AI"
2. **skill สำหรับ coding agent** (Claude Code, Codex, Cursor และตัวอื่นที่อ่าน SKILL.md ได้) ที่สอนให้ agent เขียนภาษาไทยเหมือนคนไทยเขียน แล้วตรวจงานตัวเองก่อนส่ง

## หน้าตา

```
$ node thaiproof.mjs draft.txt

draft.txt:1:19   warning  ทับศัพท์         แอพพลิเคชั่น → แอปพลิเคชัน  (ราชบัณฑิตยสภาเขียนว่า "แอปพลิเคชัน")
draft.txt:1:39   hint     คำที่ AI ชอบใช้   ในยุคดิจิทัล  (ประโยคเปิดแบบ AI ตัดทิ้งแล้วเริ่มที่เรื่องเลย)
draft.txt:1:67   hint     สำนวนแปล        ถูกออกแบบ  ("ถูก" ในภาษาไทยมักใช้กับเรื่องไม่ดี ...)
draft.txt:1:90   hint     สำนวนแปล        คุณสามารถ  (ภาษาไทยละประธานได้ ...)
draft.txt:1:99   hint     สำนวนแปล        ทำการ  (ใช้กริยาตรงๆ: "ทำการติดตั้ง" เป็น "ติดตั้ง")
draft.txt:1:143  hint     คำที่ AI ชอบใช้   ไร้รอยต่อ  (แปลจาก "seamless" คนไทยไม่ค่อยพูดแบบนี้)
draft.txt:3:159  warning  ทับศัพท์         คลิ๊ก → คลิก
draft.txt:3:167  warning  ทับศัพท์         ลิ้งค์ → ลิงก์
draft.txt:3:213  error    คะ/ค่ะ           นะค่ะ → นะคะ  ("นะ" ตามด้วย "คะ")
...
draft.txt: 1 error, 4 warning, 14 hint · กลิ่น AI: สูง (33.1 ต่อ 1,000 ตัวอักษร)
```

พอเขียนใหม่แบบคนไทย

> แอปนี้ไว้จัดการงานของทีม อัปเดตสถานะงาน แชร์ไฟล์ และดูว่าใครทำอะไรอยู่ได้ในที่เดียว ข้อมูลเข้ารหัสทั้งตอนส่งและตอนเก็บ สงสัยตรงไหนกดลิงก์ด้านล่าง หรือทักมาได้ตลอด 24 ชั่วโมงค่ะ

```
human.txt: 0 error, 0 warning, 0 hint · กลิ่น AI: ต่ำ (0 ต่อ 1,000 ตัวอักษร)
```

## ตรวจอะไรบ้าง

| ระดับ | หมวด | ตัวอย่าง |
|---|---|---|
| error | **สะกดผิด** | อนุญาติ → อนุญาต, สังเกตุ → สังเกต, ปรากฎ → ปรากฏ, กระทันหัน → กะทันหัน, กระเพรา → กะเพรา, ปฎิบัติ → ปฏิบัติ, คำนวน → คำนวณ, ลายเซ็นต์ → ลายเซ็น และอีกราว 50 คำ |
| error | **คะ/ค่ะ** | ใช่ไหมค่ะ → ใช่ไหมคะ, นะค่ะ → นะคะ, ขอบคุณคะ → ขอบคุณค่ะ |
| warning | **ทับศัพท์** ตามราชบัณฑิตยสภา | แอพพลิเคชั่น → แอปพลิเคชัน, อัพเดท → อัปเดต, ลิงค์ → ลิงก์, คลิ๊ก → คลิก, อีเมล์ → อีเมล, เซิฟเวอร์ → เซิร์ฟเวอร์, สมาร์ทโฟน → สมาร์ตโฟน และอีกราว 40 คำ |
| hint | **สำนวนแปล** | ทำการ..., คุณสามารถ..., ถูกออกแบบมา..., เพื่อให้มั่นใจว่า..., ในแง่ของ..., มีความยืดหยุ่น, ใช้ "คุณ" ถี่เกินไป |
| hint | **คำที่ AI ชอบใช้** | ในยุคดิจิทัล, ยกระดับ, ปลดล็อก, ทรงพลัง, ไร้รอยต่อ, ครบวงจร, อย่างมีประสิทธิภาพ, ไม่ว่าจะเป็น, นอกจากนี้ยัง, อีโมจิเยอะ, ! เยอะ |
| hint | **อื่นๆ** | เว้นวรรคซ้อน, ปน ครับ กับ ค่ะ, มีทั้งปี พ.ศ. และ ค.ศ. แต่ไม่ได้บอกว่าเป็นปีไหน |

โค้ดใน Markdown (ทั้ง ``` และ `inline`), URL และ HTML comment จะถูกข้าม ตัวตรวจเลยใช้กับ README ได้ตรงๆ

**"กลิ่น AI"** คือจำนวนจุดที่เป็นสำนวนแปลหรือคำที่ AI ชอบใช้ ต่อ 1,000 ตัวอักษรไทย ต่ำกว่า 3 ถือว่า "ต่ำ" ตั้งแต่ 8 ขึ้นไปถือว่า "สูง" ใช้เป็นสัญญาณให้กลับไปอ่านใหม่ ไม่ได้เป็นเครื่องจับว่าใครใช้ AI

## ใช้งาน

**บนเว็บ:** [nuttakulsv.github.io/thaiproof](https://nuttakulsv.github.io/thaiproof/) วางข้อความแล้วดูผลได้เลย ทุกอย่างทำงานในเบราว์เซอร์ ข้อความไม่ได้ส่งไปที่ไหน

**ใน terminal:** ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม

```
curl -O https://raw.githubusercontent.com/nuttakulsv/thaiproof/main/skills/thaiproof/thaiproof.mjs

node thaiproof.mjs README.md docs/*.md
pbpaste | node thaiproof.mjs              # ตรวจข้อความที่ copy ไว้ (macOS)
node thaiproof.mjs --no-royin draft.md    # ไม่ตรวจทับศัพท์
node thaiproof.mjs --no-hints draft.md    # ตรวจแค่สะกดผิดกับทับศัพท์
node thaiproof.mjs --json draft.md        # ผลแบบ JSON
```

ถ้าเจอ error จะจบด้วย exit code 1 (ใส่ `--strict` ถ้าอยากให้ warning ทำให้ fail ด้วย) เอาไปใส่ใน CI ได้เลย

```yaml
# .github/workflows/thai.yml
- run: curl -sO https://raw.githubusercontent.com/nuttakulsv/thaiproof/main/skills/thaiproof/thaiproof.mjs
- run: node thaiproof.mjs --no-hints README.md docs/*.md
```

**ในโค้ด:** ไฟล์เดียว ไม่มี dependency ใช้ได้ทั้ง Node และเบราว์เซอร์

```js
import { lint } from "./thaiproof.mjs"

const { problems, stats } = lint("ขออนุญาติแชร์ลิ้งค์นะค่ะ")
// problems: อนุญาติ → อนุญาต, ลิ้งค์ → ลิงก์, นะค่ะ → นะคะ
// stats: { errors: 2, warnings: 1, hints: 0, aiLevel: "ต่ำ", ... }
```

## ให้ agent เขียนไทยให้เป็นธรรมชาติ

Claude Code

```
/plugin marketplace add nuttakulsv/thaiproof
/plugin install thaiproof@thaiproof
```

Codex, Cursor หรือ agent อื่นที่อ่าน SKILL.md ได้

```
npx skills add nuttakulsv/thaiproof
```

พอติดตั้งแล้ว ทุกครั้งที่ agent เขียนภาษาไทย ไม่ว่าจะเป็นคำตอบ README ข้อความใน UI หรือ release note มันจะทำตาม [กฎใน SKILL.md](skills/thaiproof/SKILL.md) คือเลือกระดับภาษาให้ตรงงาน ตัดสำนวนแปล ตัดคำโฆษณา สะกดตามราชบัณฑิตยสภา ใช้ คะ/ค่ะ ให้ถูก แล้วรันตัวตรวจก่อนส่ง

ถ้าไม่ได้ใช้ coding agent จะ copy เนื้อหาใน SKILL.md ไปแปะเป็น custom instructions ของ ChatGPT, Claude หรือ Gemini ก็ได้

## ข้อจำกัด

- ตรวจจาก pattern ไม่ได้ตัดคำหรือเข้าใจความหมาย คำที่ผิดแต่ไม่อยู่ในรายการจะหลุด และอาจทักผิดในชื่อเฉพาะได้บ้าง
- รายการคำผิดมีเฉพาะคำที่รูปผิดไม่ได้เป็นคำที่ถูกในความหมายอื่น เช่น ไม่ได้ใส่ เกษียณ/เกษียน เพราะเป็นคำที่ถูกทั้งคู่แต่ความหมายต่างกัน
- คำทับศัพท์เป็นแค่ warning เพราะคนทั่วไปใช้ "แอพ" "อัพเดท" กันเยอะ จะใช้แบบราชบัณฑิตหรือไม่ก็แล้วแต่งาน ถ้าไม่อยากเห็นให้ใส่ `--no-royin`
- hint เป็นคำแนะนำ ไม่ใช่กฎ บางครั้ง "นอกจากนี้" ก็เป็นคำที่ใช่ อ่านแล้วตัดสินเองดีที่สุด

```
node --test skills/thaiproof/thaiproof.test.mjs
```
